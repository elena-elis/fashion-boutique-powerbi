# 👗 Fashion Boutique — Power BI Dashboard

Интерактивный дашборд для анализа продаж модного бутика. 
Визуализация ключевых метрик.

Дашборд построен на основе датасета [Retail Fashion Boutique — Sales Analytics 2025](https://www.kaggle.com/datasets/pratyushpuri/retail-fashion-boutique-data-sales-analytics-2025).

## 📋 Данные и предобработка

**Источник:** Kaggle — Retail Fashion Boutique Data (Sales Analytics 2025).  
**Основная таблица:** `fashion_boutique_dataset.csv`.  
**Описание датасета:** содержит транзакции розничных продаж модного бутика за 2024–2025 гг. 
Включает атрибуты товаров (бренд, категория, размер, цвет, сезон), цены (оригинальная, текущая, процент скидки), данные о продажах и возвратах (дата покупки, статус возврата, причина возврата), а также оценки клиентов. 
Датасет ориентирован на анализ влияния скидок, сезонности и характеристик товара на выручку, возвраты и удовлетворённость покупателей.

**Исключённые данные:**  
Из анализа исключены транзакции за **6 августа 2025 г.**  
**Причина:** в этот день зафиксирован аномальный всплеск выручки, существенно искажающий средние показатели и тренды. 
Значение требует дополнительного изучения (возможны технические ошибки выгрузки, единичные оптовые заказы или некорректные цены). 
Для обеспечения достоверности метрик (средний чек, доля скидок, динамика по кварталам) данные за эту дату были отфильтрованы на этапе ETL в Power Query.

**Основные преобразования в Power Query:**
*   Приведение типов данных (даты, числа, текст).
*   Создание производной колонки `price_tier` (Budget, Mid-Range, Premium, Luxury).
*   Фильтрация аномальных дат (6 августа 2025 г.).
*   Создание справочников `dim_price` и `dim_size` для корректной сортировки.

**Ассеты и оформление:**  
Фоновые изображения (арт‑иллюстрации) для оформления дашборда взяты с платформы Pinterest из материалов свободного доступа.
Использованы в некоммерческих целях для улучшения UX и тематической стилизации аналитической панели.

## 📊 Ключевые визуализации

На дашборде представлены следующие графики и метрики:

1.  **KPI-карточки (в центре справа):**
    *   **Общий доход:** (после исключения аномалий).
    *   **Количество заказов:** 
    *   **Средний чек:** 
    *   **Средний рейтинг:**

2.  **Динамика выручки по кварталам (верхний график):**  
    Столбчатая диаграмма с разбивкой на товары со скидкой (`Discounted`) и по полной цене (`Full Price`). Позволяет оценить сезонность и влияние распродаж на выручку.

3.  **Выручка по ценовым сегментам (средний график):**  
    Линейно-столбчатая диаграмма, показывающая распределение выручки по сегментам: Budget, Mid-Range, Premium, Luxury. Отражает структуру продаж и вклад каждого сегмента.

4.  **Выручка по категориям товаров (нижний график):**  
    Столбчатая диаграмма с разбивкой по категориям (Outerwear, Shoes, Dresses, Tops, Bottoms, Accessories) и типу цены.
    Помогает выявить наиболее прибыльные категории и зависимость от скидок.

6.  **Фильтры по брендам (слева):**  
    Срезы (Ann Taylor, Banana Republic, Forever21, Gap, H&M, Mango, Uniqlo, Zara) позволяют анализировать показатели по каждому бренду отдельно.

## 🧮 DAX-меры (ключевые)

*   `Total_Revenue = SUM('fashion_boutique_dataset'[current_price])`
*   `Total_Orders = COUNTROWS('fashion_boutique_dataset')`
*   `Avg_Order_Value = DIVIDE([Total_Revenue], [Total_Orders])`
*   `Avg_Rating = AVERAGE('fashion_boutique_dataset'[customer_rating])`
